### 🚀 Major Project
#### 🩺 **Ultra-Lightweight RISC-V Architecture for Anomaly Detection in Healthcare Applications**
- Designed and implemented a **Day–Night RISC-V processor architecture** featuring:
  - **Main Core (Day Mode):** High-performance pipeline for active operation  
  - **All-Night Core (Night Mode):** Always-on, ultra-low-power sub-core for continuous anomaly detection  
- Complete **ASIC flow** implemented using:
  - **Synopsys Toolchain:**  
    - *VCS* – Functional Verification  
    - *Design Compiler (DC)* – Synthesis, Power, and Timing Analysis  
    - *IC Compiler II (ICC2)* – Floorplanning, Placement, and Routing  
    - *PrimeTime* – Static Timing and Power Verification  
  - **Cadence Toolchain:**  
    - *Innovus* – Physical Design & Optimization  
    - *Voltus* – Power Integrity and IR Drop Analysis  
- Targeted **SAED32HVT technology** at **ff0p95v125c corner** for ultra-low power operation.  
- Compared **power, energy, and area metrics** against **ORCA** and **Rocket** cores.  
- Intended for **wearable biomedical SoC platforms** supporting always-on anomaly detection.
