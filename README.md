### 🚀 Major Project
#### 🩺 **Ultra-Lightweight RISC-V Architecture for Anomaly Detection in Healthcare Applications**
- Designed a **Day–Night RISC-V Processor Architecture** featuring:  
  - **Main Core (Day Mode):** High-performance pipeline for active tasks  
  - **All-Night Core (Night Mode):** Always-on, ultra-low-power sub-core for continuous anomaly detection  
- Complete **ASIC flow implemented** using **Synopsys**:  
  - *VCS* – Functional Verification  
  - *Design Compiler* – Synthesis, Power, and Timing Analysis  
  - *IC Compiler II* – Floorplanning, Placement, and Routing  
- Targeted **SAED32HVT 32nm technology** at **ff0p95v125c** for ultra-low-power operation  
- Compared **power, energy, and area** against **ORCA** and **Rocket** cores
